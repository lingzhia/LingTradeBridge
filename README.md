# LingTradeBridge

LingTradeBridge 是 LingQuant 的**交易信号跟单桥**：接收外部策略产生的交易信号，并将信号转换为交易客户端可以执行的操作。

它位于“策略信号”和“交易客户端”之间，不负责完整的策略研究、金融数据基础设施或策略运行引擎。

## 在系统中的位置

```text
外部策略或策略运行环境
          │
          │ 交易信号
          ▼
   ┌───────────────┐
   │ LingTradeBridge│
   │   信号跟单桥    │
   └───────┬───────┘
           │
           │ 交易客户端操作
           ▼
       同花顺等交易客户端
```

## 主要职责

- 接收外部策略发送的交易信号。
- 对信号进行接收和转换。
- 将交易信号交给交易客户端执行。
- 提供跟单运行界面、配置和运行日志。
- 保存跟单相关的本地状态和记录。

## 信号来源

当前项目代码包含两种信号接收方式：

- Redis：跟单器从配置的 Redis 通道接收实时信号。
- HTTP：本地 HTTP 服务通过 `POST /signal` 接收信号。

HTTP 服务提供 `GET /health` 健康检查接口。具体信号字段、配置项和执行规则以当前代码及配置文件为准。

## 启动

macOS 下可在访达中双击：

```bash
open 启动跟单器.command
```

也可以在终端运行：

```bash
cd LingTradeBridge
./启动跟单器.command
```

启动脚本会优先使用项目目录下的 `.venv/bin/python`，否则使用 `python3`。

使用同花顺客户端操作能力时，需要按 macOS 的要求授予终端或 Python 辅助功能权限。Redis 跟单还需要准备对应的 Python 依赖和 Redis 服务。

## 与其他子项目的关系

| 项目 | 关系 |
|---|---|
| `LingStrategies` | 提供策略代码和研究资料；本项目不负责策略研究。 |
| `LingRun` | 提供本地策略运行能力；本项目是独立的信号接收与跟单路径。 |
| `LingJQcli` | 提供聚宽平台工具；策略信号可以来自聚宽相关运行环境。 |
| `LingData` | 提供金融数据基础设施；本项目不负责数据存储和查询。 |
| `webconsole` | 提供统一控制台；本项目当前通过自己的启动入口运行。 |

本项目 README 只说明系统职责和使用入口，不将某一条信号来源或交易路径定义为整个 LingQuant 的统一生产流程。
